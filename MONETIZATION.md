# Monetization Strategy — dirfmt portfolio

## Revenue Streams

### 1. dirfmt — PyPI CLI Tool (Freemium)

**Model:** Free base tool + paid Pro version
- Free: basic file organization by type/date/extension
- Pro ($9.99/mo or $49/yr): batch processing, custom rules, watch mode, priority support

**Distribution:**
- PyPI (`pip install dirfmt`) for organic discovery
- GitHub repo for awareness and contributors
- Publish to Homebrew (macOS) for wider reach

**Revenue estimate:** 1000 downloads → 2% conversion → $20/mo recurring = $40/mo = ~$480/yr

### 2. readmegen — NPM CLI Tool

**Model:** Free + paid Pro with advanced templates
- Free: basic README generation
- Pro ($4.99/mo or $19/yr): custom templates, AI-powered descriptions

**Distribution:**
- npm (`npm install -g readmegen`)
- npm search visibility

**Revenue estimate:** 5000 weekly downloads → 1% conversion = $19/user × 50 = $950/mo = ~$11K/yr
